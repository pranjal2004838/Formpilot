The Multi-Agent Coworkers

ARCHITECTURE

The 5 AI Coworkers Working Together

Instead of writing one massive, confusing code block to handle everything, FormPilot breaks the task down and hires five specialized AI mini-robots (Agents). Each agent has one job and does it flawlessly.

👁️

Agent 1: The Scanner

Analyzer: Looks at your Aadhaar or Passport. Uses Gemini Vision to scan the image and convert it into clean digital text structures.

⚖️

Agent 2: The Lawyer

Auditor: Compares scanned details against country rules (YAML parameters). Checks age boundaries and format layouts to confirm eligibility.

🧩

Agent 3: The Matchmaker

Field Mapper: Matches extracted values to chaotic fields in blank PDFs using semantic reasoning and fuzzy matching fallbacks.

🖌️

Agent 4: The Artist

PDF Generator: Programmatically draws values into pixel-perfect PDF forms via ReportLab. Publishes documents to Microsoft SharePoint and notifies Slack channels.

🤖

Agent 5: The Submitter (Playwright)

Browser Automation: Launches Playwright Chromium, discovers input selectors on target web portals, fills them, solves password portals, and completes live form submission.

Governance & Anti-Bot Bypass

DOUBLE HITL

Double-HITL Governance: Rules & Anti-Bot Safety Valve

Standard automated bots crash or lock up when encountering two things: **Rules violations** (e.g. minor ages applying without parental signature) or **Browser anti-bot security challenges** (like CAPTCHAs or OTP gates).

FormPilot handles this with a unique **Double-HITL (Human-in-the-Loop) safety architecture**:

⚖️

1. Compliance Gate: Pauses workflow and alerts Slack if business rules are violated, waiting for reviewer approval.

🔒

2. Browser Security Gate: Playwright detects CAPTCHA/OTP, pauses the browser context, registers awaiting_user_interaction, and lets the human resolve it before resuming successfully.
