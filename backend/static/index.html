Enterprise-Grade Capabilities

🤖
Airia-Orchestrated Pipeline
Every agent step is registered in Airia Community as a callable tool. The pipeline is published and can be invoked from any Airia workspace or workflow.
👤
Human-in-the-Loop (HITL)
When eligibility fails, the pipeline pauses. A Slack approval card with Approve/Reject buttons is sent. The workflow resumes only after human sign-off.
💬
Slack Block Kit Notifications
Rich Slack notifications on completion with applicant details, confidence scores, and PDF metadata. HITL requests include Approve/Reject action buttons.
📁
SharePoint Archival
Generated PDFs are automatically uploaded to a SharePoint document library via Microsoft Graph API, organized by date, with applicant metadata.
🔍
Gemini 2.0 Flash Vision
95%+ OCR accuracy on Aadhaar, Passport, PAN, and Driving Licence using Google's latest multimodal model with per-field confidence scoring.
🌍
Compliance Rule Engine
Deterministic policy checks for UIDAI Aadhaar, GSTIN format, Indian state-pincode consistency, and cross-country eligibility workflows.
